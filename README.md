Program created so that companies can contact a large number of customers more easily, the program reads the contacts in a spreadsheet, takes the phone number and sends the messages via Whatsapp Web,
After sending the messages, the program updates the spreadsheet, informing which people have already been contacted, and the date the contact took place, when running the program normally,
If contact with a customer has been in place for more than 30 days, the program sends a different message, offering a restock.
